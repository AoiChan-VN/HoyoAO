==================================================
DESIGN PHILOSOPHY
==================================================

This is NOT a traditional Skybox project.

DO NOT implement:

Skybox
├── front
├── back
├── left
├── right
├── top
└── bottom

A 6-face skybox is only a static visual shell and does not create believable spatial depth.

Instead implement:

Multi-Layer Environment System

combined with

Independent Sky System

to simulate how human vision perceives depth, distance, atmosphere and scale.

==================================================
WORLD DEPTH MODEL
==================================================

Camera observes multiple depth zones.

Layer Order:

Layer 0
UI Layer

Layer 1
Near Layer

Layer 2
Mid Layer

Layer 3
Far Layer

Layer 4
Horizon Layer

Layer 5
Atmosphere Layer

Sky System

Layer 6
Deep Space Layer

==================================================
LAYER RESPONSIBILITIES
==================================================

UI Layer

Purpose:

- HUD
- Debug Overlay
- FPS Monitor
- Developer Tools

Near Layer

Purpose:

- Floating Cubes
- Cube Fragments
- Particles
- Debris
- Foreground Elements

Highest parallax movement.

Mid Layer

Purpose:

- Matrix Cubes
- Cube Clusters
- Main Gameplay Objects
- Interactive Objects

Primary scene content.

Far Layer

Purpose:

- Mega Structures
- Massive Cubes
- Distant Architecture
- Large Grids

Reduced parallax movement.

Horizon Layer

Purpose:

- Skyline
- Horizon Geometry
- Distance Glow
- Landscape Silhouettes

Creates visual transition into atmosphere.

Atmosphere Layer

Purpose:

- Fog
- Mist
- Light Shafts
- Volumetric Illusions
- Atmospheric Noise

Creates perceived scale.

Deep Space Layer

Purpose:

- Deep Background
- Infinite Space
- Remote Cosmic Content

Lowest parallax movement.

==================================================
SKY SYSTEM
==================================================

Sky is NOT a layer.

Sky is a dedicated subsystem.

Purpose:

- Sky generation
- Celestial objects
- Atmospheric simulation
- Space simulation

The sky subsystem exists independently from world layers.

Architecture:

SkySystem
├── StarField
├── NebulaField
├── AtmosphericScattering
├── CelestialObjects
└── SkyRenderer

Responsibilities:

StarField

- stars
- star clusters
- procedural distribution

NebulaField

- nebula clouds
- cosmic fog
- distant visual formations

AtmosphericScattering

- horizon tint
- altitude fading
- atmospheric color blending

CelestialObjects

- planets
- moons
- suns
- distant structures

SkyRenderer

- rendering order
- depth ordering
- sky composition

==================================================
PARALLAX SYSTEM
==================================================

Each depth layer uses a unique parallax factor.

Example:

Near Layer
factor = 1.0

Mid Layer
factor = 0.5

Far Layer
factor = 0.25

Horizon Layer
factor = 0.10

Atmosphere Layer
factor = 0.05

Deep Space Layer
factor = 0.01

Rules:

Objects closer to camera move more.

Objects farther from camera move less.

Never move all layers equally.
