# Quan trọng:
- Cấm AI đặt tên cho class - namming - code - string,.... Bị trùng lặp với Godot > dẫn đến bị Shadow\_Variant - UNUSED\_SIGNAL,... Các name example của godot dẫn đến Code và game của tôi hoạt động không ổn định và bị ảnh hưởng.
- Tôi cần bạn đóng gói 5 Prompt AI cho Qwen3.8-Max để làm tài liệu sử dụng cho dự án này.
- Cần dầy đủ các luật khắt khe tuyệt đối để giảm thiểu sự sai sót và lỗi xuống mức thấp tuyệt đối 0.1/100% (nghĩa là chỉ được phép sai sót 0.01%).
- Cần đầy cả các luật AI khi Code > Cấm AI tạo các code placeholder - rỗng - giả - die,... Cấm AI gửi các Code Block thiếu hoặc không toàn vẹn.
- Đồng thời Khi refactor bất kỳ file code nào khi cập nhập thêm hoặc sửa lỗi > Đều phải gửi lại tôi theo dạng file code hoàn thiện > Cấm AI bắt tôi phải tự lắp ghép và sửa từng đoạn code,...
- AI phải đọc lại Code và dự án để tránh tình trạng AI quên kiến trúc và Code > Dẫn đến ngày càng sai và Tự ý thay đổi Naming,...
