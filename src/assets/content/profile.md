# AoiChan - (KanaChan)

Tôi là một lập trình viên chuyên nghiệp chuyên tối ưu hóa trải nghiệm không gian số. Thích ứng nhanh với công nghệ mới và luôn ưu tiên kiến trúc mã nguồn sạch, mô-đun hóa tuyệt đối.

### Kỹ Năng Cốt Lõi
* Vanilla ES6+ Modules / Custom Web Components
* WebGL / Canvas / 3D Spatial Matrix Mathematics
* Performance Optimization / Low-latency Rendering
* Clean Architecture / Configuration Driven Design
